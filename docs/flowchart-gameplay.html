Catwalk gameplay rules

What the code does today. Read from the implemented rules, not from the plan.

1. Opening the app

Each open reads the phone, judges every finished day since the last open, then sets the cat's state.

  • Today does not count as missed until it ends.
  • A freeze cannot rescue a cat that has already run away.

2. What today's steps do

These pay once a day. Opening the app again cannot pay them twice.

  • XP is proportional to the goal: 50 at 6,000 steps, 25 at 3,000, 100 at 12,000 (between 20 and 250).
  • The quest needs hourly step data, so a sensor-only phone only gets "beat yesterday".

3. Bringing a runaway cat home

Two routes. The map is the normal one; the weekly walk is the fallback when location is not usable.

  • "No" on location means it is off, denied or unreadable.
  • 84,000 steps in 7 days at a 6,000 goal. The goal is read at the moment, so a higher goal asks for more.
  • A streak freeze never rescues a cat that has already run away.

4. Map pickups

Pickups are fixed per area and date, so reopening the map does not reroll them.

  • A found toy lies on the room floor and the cat plays with it. A freeze covers one missed day.
  • Cat progress is in the reward table with weight 0: it has nowhere to go until there is more than one cat.
