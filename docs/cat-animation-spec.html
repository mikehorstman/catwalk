Cat animation spec

What to draw, and how to hand it over.

The short version. Draw the cat facing right on a transparent sheet. Keep the fur in greys, and put eyes, nose, mouth, inner ears and whiskers on a second sheet. Export one PNG per action per mood, list them in assets/cats/manifest.json, and the room plays them. Anything you have not drawn keeps using the placeholder.

Example sheet

docs/cat-spritesheet-example.png shows every action and frame count on a placeholder cat, with the red foot line. docs/cat-spritesheet-example-strips/ has the same cat as real-format strips (one row, transparent, no guide marks), a fur and a details file per action. Rebuild with uv run --with pillow python tools/make_example_sheet.py.

Why two sheets per action

All three cat colours come from one drawing. The fur sheet is greyscale and gets multiplied by the cat's colour. The details sheet is drawn on top, untouched.

Without the split, the eyes and nose would be tinted too, and a charcoal cat would have a charcoal nose. The two sheets share exactly the same frame size, frame count and frame order, so they line up frame for frame.

Frames and the foot anchor

  • One row per sheet, left to right, equal frame boxes.
  • Frame size is yours, but keep it the same for every sheet: frameSize in the manifest.
  • The cat's feet sit at the same pixel in every frame. Report that point once as footAnchor, measured from the frame's top-left. This is what keeps her standing on the floor line instead of floating when the pose changes.
  • Draw facing right. The app flips the whole frame for the other direction.

Actions

ActionWhen it playsNotes
walkWalking along the floorLoop. A side-on gait.
sitSitting, often on the rugLoop or a short settle.
sleepSleeping in the basketUsually a one-shot that holds.
groomWashing a pawLoop.
idleStanding still, looking aroundLoop.
perchSitting up high: cat tree, window sillLoop. Drawn as seen from the room, not from above.
climbUpGoing up to a high spotLoop. Travels vertically, so keep the body vertical.
playBatting at a toy found on the mapLoop. Plays beside the toy on the floor, so keep it on the floor line.
climbDownComing down againLoop.

Moods

Each action can have three versions: happy, neutral, sad.

  • Missing moods are fine. A lookup for a mood you have not drawn falls back to neutral, and then to the placeholder.
  • So start with neutral for an action, and add the other two whenever you like, with no app change.
  • Mood changes the look; the game rules already decided the mood. The room never picks a mood, it only asks for one.
  • If the mood changes mid-action the sheet swaps on the next frame, without restarting the action.

The manifest

{
  "frameSize": [256, 256],
  "footAnchor": [128, 236],
  "actions": {
    "walk": {
      "neutral": {
        "fur": "walk_neutral_fur.png",
        "details": "walk_neutral_details.png",
        "frames": 8,
        "fps": 10,
        "loop": true
      },
      "happy": {
        "fur": "walk_happy_fur.png",
        "details": "walk_happy_details.png",
        "frames": 8,
        "fps": 12
      }
    },
    "sleep": {
      "neutral": {
        "fur": "sleep_neutral_fur.png",
        "frames": 4,
        "fps": 2,
        "loop": false
      }
    }
  }
}
  • details and loop are optional. loop defaults to true.
  • loop: false holds the last frame, which is how "lie down and stay down" works from a single short sheet.
  • Action and mood names are the ones in the tables above, spelled exactly.
  • Anything in the file the app does not recognise is ignored, so you can draft an action before it exists in the code.

Previewing your art

In a debug build, tap the flask button in the top-left of the room. The animation lab loops one action of your choice, flips it, shows the foot line, and puts cream, charcoal and ginger side by side so you can see how the tint treats your shading.

Charcoal is the one to watch. A dark tint multiplying an already dark drawing crushes the shading into a silhouette. Keep the fur shading in the mid greys rather than pure white or black. The lab shows all three colours at once, so check it there before drawing a whole set.
